# 서울 스타트업 지도

서울에 있는 투자유치 스타트업을 지도 한 장에 모았습니다. 히트맵으로 채용이 몰린 동네를 보고, 버블을 누르면 회사 상세와 지금 열린 공고를 바로 볼 수 있습니다.

## 화면에서 볼 수 있는 것

| 항목 | 출처 |
|---|---|
| 채용공고, 게시일, 마감일, 고용형태(정규직/계약직 등), 전형단계, 지원 링크 | 원티드 |
| 위치, 설립연도, 분야, 회사 소개, 복지 태그, 지원자 응답률 | 원티드 |
| 인원, 평균연봉 | 국민연금 가입 기준 (원티드 제공) |
| 매출 | KODATA (원티드 제공) |
| 최근 입사/퇴사, 순증 | 원티드(최근 월) / 국민연금 공공데이터 API (키 설정 시 12개월) |
| 투자단계, 투자 횟수, 대표자, 한국계/외국계 | THE VC 공개 프로필 |
| 누적 투자 | 원티드 태그 기준 구간 (100억 이상, 예비/아기 유니콘) |
| 혁신의숲, 잡플래닛, 블라인드, 사람인, 잡코리아, 그룹바이, 로켓펀치, 캐치, 링크드인 | 회사별 바로가기 링크 |

## 스타트업 선정 기준

1. 원티드에 서울 근무지 공고가 있는 회사
2. 상장사, 대기업, 1,000명 초과 제외
3. 원티드 투자 태그(누적투자 100억 이상, 예비/아기 유니콘, 유니콘브릿지, VC 포트폴리오 등)가 있거나, THE VC에서 투자 라운드가 확인된 회사

## 자동 갱신

`.github/workflows/update.yml` 이 매일 06:00 (KST) 에 돌면서

- 서울 공고 전체를 다시 받고, 닫힌 공고는 빼고 새 공고는 상세(게시일, 전형, 고용형태)까지 채웁니다
- 새로 나타난 회사 중 조건에 맞는 곳을 추가합니다
- 회사 지표는 7일, THE VC 정보는 30일 주기로 새로고침합니다

Actions 탭에서 `데이터 갱신` 을 수동 실행할 수도 있습니다.

### 12개월 입사/퇴사 (선택)

[공공데이터포털 국민연금 가입 사업장 내역 API](https://www.data.go.kr/data/3046071/openapi.do) 활용신청 후 받은 일반 인증키(Decoding)를
레포 Settings > Secrets and variables > Actions 에 `DATA_GO_KR_KEY` 로 넣으면 매일 월별 취득/상실 인원을 쌓아 최근 12개월 입사/퇴사를 계산합니다.

## 로컬 실행

```bash
node scripts/update.mjs --build-only   # data/state.json 으로 companies.json 재생성
python3 -m http.server 8000            # http://localhost:8000
```

- 누적 투자금액, CTO 이력처럼 로그인이나 유료 플랜 뒤에 있는 정보는 넣지 않았고, 대신 검색 링크를 달았습니다.
